Tiny Tapeout Power Gates for GF180mcuD
======================================

* `tt_pg_3v3_hp_1`: Single height 3.3V switch (high-performance variant)
* `tt_pg_3v3_hp_2`: Dual   height 3.3V switch (high-performance variant)
* `tt_pg_3v3_hp_4`: Quad   height 3.3V switch (high-performance variant)
* `tt_pg_5v0_2`: Dual height 5.0V switch

Design and layouts were done by Sylvain Munaut.
